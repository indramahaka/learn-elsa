          Welcome

          AWFS Elsa Academy

          Your personal learning reference for Elsa Workflows 3.x, anchored to the Approval Workflow Service (AWFS) for Toyota-Astra Motor. Built for one architect, under pitch deadline.

          How to use this site

          Each topic has four tabs: Concept (the mental model and AWFS connection), Code (working samples with explanations), Hands-On (an exercise you run locally), and Self-Check (questions that mirror TAM CTO Q&A style). Work through Tier 1 first. Return to Tier 2 before detailed design sessions. Check Tier 3 when the CTO goes deep.

          The three tiers

          • Tier 1: Must Know (9 topics). Non-negotiable for the pitch. Hold all of these in working memory before walking into TAM.
          • Tier 2: Should Know (7 topics). Comes up in design sessions and detailed Q&A. Be fluent, not necessarily fast.
          • Tier 3: Nice to Know (5 topics). Escape hatches for deep questions. Know they exist; find them when needed.

          Progress tracking

          Mark topics complete using the button at the bottom of each topic. The thin bar at the very top of the page and the circles in the sidebar both reflect your session progress. Progress resets when you reload the page. This is intentional: the goal is daily active review, not a one-time checkbox exercise.

          Keyboard shortcuts

          • Ctrl+K / Cmd+K: Focus search
          • 1 2 3 4: Switch tabs when focused on a topic
          • J / K: Next / previous topic

          Start here

          If this is your first session, start with T1-01: Mental Model and Setup. It lays the conceptual foundation for every other topic. You can navigate using the sidebar on the left or by pressing J to step forward through topics in order.

          The pitch context

          This is not a generic Elsa tutorial. Every concept connects to a real TAM requirement: POA delegation (Persetujuan), MDM org hierarchy lookup for dynamic approver resolution, multi-level sequential approval, SLA escalation via WhatsApp notification, and the 4-step workflow wizard your team will build. The hands-on labs build a mini-AWFS you can demo in the pitch. The cheat sheet prepares you for the CTO Q&A.

          If a code sample or claim in this site is marked [verify against current Elsa docs], do not cite it in the pitch until confirmed. Better to flag a gap than to state a wrong answer in the room.
